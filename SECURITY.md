# Security policy

Security fixes target the current development line and ship in new releases.
Use the latest qualified release; older releases do not have a separate backport
support promise. See [releases](https://github.com/Dockpipe-Industries/dockpipe-packages/releases).

Report undisclosed vulnerabilities through
[GitHub private security reporting](https://github.com/Dockpipe-Industries/dockpipe-packages/security/advisories/new).
Include affected versions/platforms, impact and a minimal reproducer. Coordinate
any disclosure with the maintainers rather than publishing exploit details in an issue.

Dependabot and CodeQL complement review and tests. Their configuration uses standard
public-repository GitHub features and public Ubuntu runners; it does not enable
paid add-ons or guarantee that every vulnerability will be detected.
